## 🧑‍💻 About Me

I'm an **AI/ML engineer and backend developer** from India with **5+ years** of experience building production systems where machine learning meets solid backend engineering.

- 🤖 I design and ship **GenAI products**: RAG pipelines, LLM agents, document intelligence and conversational assistants
- ⚙️ I build **high-throughput backend services** with Python (FastAPI, Django), async I/O, queues and caching
- 🔎 I work with **search and retrieval** at scale: vector databases, hybrid search, embeddings and re-ranking
- 🧠 I've worked on **classical ML and computer vision**: recommendation systems, face recognition, speaker-state detection and virtual try-on
- 🚀 I take models **from notebook to production** with Docker, CI/CD, observability and cloud deployment
- 🌱 I'm currently going deeper into **agentic workflows, LLM evaluation and inference cost optimization**
